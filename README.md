## 📱 Sobre o Projeto

O **React Test Mobile-Desktop** foi desenvolvido para validar conceitos de **Design Responsivo** dentro do ecossistema React. O objetivo principal é criar componentes que se comportem de maneira dinâmica dependendo da resolução da tela, sem perder a usabilidade.

### ✨ O que está sendo testado/demonstrado?

- [x] **Responsividade:** Uso de *Media Queries* e *Flexbox/Grid* para adaptação de layout.
- [x] **Componentização:** Criação de componentes reutilizáveis que funcionam em diferentes contextos.
- [x] **Estado & Props:** Gerenciamento de dados no frontend.
- [ ] **Hooks:** (Se aplicável) Uso de `useEffect` para detectar redimensionamento de janela.

## 🛠 Tecnologias

As principais ferramentas utilizadas na construção deste projeto:

* **[React.js](https://reactjs.org/):** Biblioteca principal para construção da UI.
* **JavaScript (ES6+):** Lógica de interação.
* **CSS3 / Styled Components:** Estilização e regras de responsividade.
* **NPM/Yarn:** Gerenciamento de pacotes.
